# 🐍 Yılan Oyunu (Snake Game)

Python və Tkinter ilə hazırlanmış klassik Yılan (Snake) oyunu.

## 🎮 Xüsusiyyətlər

- Klaviatura ox düymələri ilə idarəetmə (Yuxarı/Aşağı/Sol/Sağ)
- Real vaxtda skor sayğacı
- Toqquşma aşkarlanması (divarlar və ilanın öz bədəni ilə)
- Yeyildikcə uzanan ilan və təsadüfi yerləşən yem (food)
- Oyun bitəndə "GAME OVER" ekranı

## 🛠️ İstifadə olunan texnologiyalar

- Python 3
- Tkinter (Canvas ilə qrafika və animasiya)
- random modulu (yemin təsadüfi yerləşdirilməsi üçün)

## 🚀 Necə işə salmaq olar

```bash
python snake.py
```

## 🕹️ İdarəetmə

| Düymə | Hərəkət |
|-------|---------|
| ↑ | Yuxarı |
| ↓ | Aşağı |
| ← | Sola |
| → | Sağa |

## 💡 Gələcək planlar

- Sürətin tədricən artması (level sistemi)
- Ən yüksək skorun (high score) yadda saxlanması
- Səs effektləri əlavə etmək
- Pause/Restart funksiyası
